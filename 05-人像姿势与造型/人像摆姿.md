# 人像摆姿

## 先说问题

原笔记只有四条：破线破面、找支点、道具、情境导入。方向对，但太简，实战时不知道怎么落地。

这一篇把四条展开成可操作的步骤，并解释"为什么"。

## 一、破线、破面：让身体不"板"

人体如果正对镜头、双肩齐平、双腿并拢，就是一个"平面"，拍出来又宽又僵。

**破线**：打破身体的直线。

- 肩线：一高一低、一前一后；
- 胯线：往一侧顶，和肩形成反向倾斜；
- 腿线：一腿承重、一腿伸出或交叉；
- 手臂：不要贴紧身体，留出空隙（"手臂和腰之间要有光"）。

**破面**：不要让胸、胯、脸都朝同一个方向。

- 身体朝 45°，脸转回 30°，形成"身体侧、脸正"；
- 或者身体正、脸侧，形成"看别处"的故事感。

注意：**破要"破得协调"**。肩歪 30°、胯歪 30°、头再歪 30°，就散架了。通常一个主方向（身体 45°）+ 一个小反方向（头 15°）就够。

## 二、找支点：让身体"有地方靠"

支点是身体的"受力点"，有支点姿势才稳、才有层次：

| 支点 | 做法 | 效果 |
|---|---|---|
| 墙/柱子 | 肩、背、手靠墙 | 放松、有依托 |
| 椅背/桌沿 | 手撑、肘搭 | 上半身前倾，显腰线 |
| 膝盖 | 坐姿手肘撑膝 | 稳定、亲近 |
| 地面 | 蹲、坐、躺 | 自然、生活感 |
| 道具 | 手扶包、杯、花 | 手有去处 |

没有支点时，人会"悬着"，肩会耸、手会僵。**先找支点，再谈姿势。**

## 三、道具：给手一个理由

道具的作用不是"好看"，是**解决"手没地方放"和"不知道做什么"**。

常用道具：

- 帽子、围巾、墨镜（可戴、可拿、可扶）；
- 杯子、书、花、相机、手机；
- 伞、气球、泡泡机；
- 椅子、毯子、野餐篮。

原则：道具要和场景/服装同一套语言。穿礼服拿搪瓷杯就出戏。

## 四、情境导入：让她"在故事里"

直接喊"看镜头笑"最假。给她一个情境：

- **听**："你听到后面有人叫你。"
- **闻**："你闻到花香，闭眼吸一口。"
- **看**："你看到远处海面上有个东西。"
- **做**："你在等一个人，有点着急。"
- **感受**："风有点大，你护一下头发。"

情境会自然产生眼神、手部动作、身体朝向，比"摆"真实得多。

## 五、一套完整的摆姿流程

1. **定支点**：让她靠/坐/扶，先稳下来；
2. **破线**：调肩、胯、腿，形成三角形或 S 形；
3. **给手**：道具或动作，解决手的位置；
4. **转头**：身体 45°、脸转回，或脸侧看别处；
5. **给情境**：一句话让她"进入状态"；
6. **连拍**：抓过渡瞬间，选最自然的一张。

## 六、常见错误

| 错误 | 表现 | 修正 |
|---|---|---|
| 破得太猛 | 肩胯头各歪一个方向，散架 | 一个主方向 + 一个小反方向 |
| 手臂贴腰 | 手臂和身体之间没有空隙，显胖 | 手臂离开身体，留出"光" |
| 双手下垂 | 手不知道放哪，僵硬 | 给道具/插兜/扶墙 |
| 正对镜头 | 又宽又平 | 身体侧 30°–45° |
| 重心平均 | 双腿并拢站直 | 单腿承重，另一腿伸出 |
| 口令抽象 | "自然一点" | 具体动作/情境 |

## 七、练习方法

- 对着镜子，把"立正"改成"三角形"，看差别；
- 找一面墙，练"靠、扶、撑"三种支点；
- 拿一个杯子/帽子，练"手有事做"；
- 给自己一句情境（"等车""听到名字"），拍 10 张连拍，选最自然的一张。

## 要点回顾

- 破线破面 = 打破直线和同向平面，但要协调。
- 支点让身体稳，道具让手有事做。
- 情境导入比"摆姿势"更自然。
- 流程：支点 → 破线 → 给手 → 转头 → 情境 → 连拍。

> 参考：Roberto Valenciano《Picture Perfect Practice》；Lindsay Adler《Posing Guide》。

# LUT 与尼康 N-Log 标准 LUT

## 先说问题

网上流传一批 `.cube` 文件，名字里带 `N-Log` 和 `RED_` 前缀，被当成"尼康标准 LUT"到处转发。套上去之后，有人觉得"通透"，有人觉得"偏色、对比怪"。

原因是：**这批文件是 RED 摄影机 IPP2 体系下的 LUT，不是尼康官方 N-Log LUT。**两者 Log 曲线不同，混用必然偏色。

这一篇先把"LUT 是什么、有哪几类"讲清楚，再说明为什么不能混用，最后给正确的使用顺序。

## 一、两种 LUT，别混为一谈

| 类型 | 作用 | 例子 | 能不能改 |
|---|---|---|---|
| 技术转换 LUT（Technical LUT） | 把 Log 映射到显示空间（Rec.709） | N-Log → Rec.709 | 不应用来调风格 |
| 风格 LUT（Creative LUT） | 在转换后叠加影调/色彩风格 | 青橙、漂白旁路、胶片 | 可叠、可调强度 |
| 监看 LUT（Monitoring LUT） | 只作用于监视器，不写文件 | 机内/外接监视器 | 不影响素材 |

**技术 LUT 是"翻译"，风格 LUT 是"化妆"。**先翻译，再化妆；顺序反了，连曝光判断都会失真。

## 二、尼康官方的 N-Log LUT

尼康在官网提供 N-Log 3D LUT 下载，常见文件名形如：

- `N-Log_to_REC709_33grid_V1.cube`（10bit N-Log → Rec.709）
- 部分机型附带 `N-Log_to_REC2020_HLG` 版本，用于 HDR 输出

特点：

- 只做色彩空间和伽马转换，**不带风格**；
- 转换后画面中性、偏平，方便二次调色；
- 必须配合 N-Log 拍摄（10bit、基准 ISO 800）使用。

## 三、RED 的 IPP2 LUT 命名怎么读

以 `RED_Achromic_Rec2020_Log3G10_to_Rec709_BT1886.cube` 为例：

| 字段 | 含义 |
|---|---|
| `RED_` | RED 摄影机体系 |
| `Achromic` | 中性、无色偏的映射风格 |
| `Rec2020` | 输入色域 Rec.2020 |
| `Log3G10` | 输入 Log 曲线（RED 的 Log3G10） |
| `to_Rec709` | 输出色彩空间 |
| `BT1886` | 输出伽马曲线 |

原文把这批文件的输入写成 `N-Log`，这是关键错误：**RED 的 Log 曲线是 Log3G10，不是尼康 N-Log。**把 Log3G10 的 LUT 套在 N-Log 素材上，等于用"另一套对数曲线"去解码，暗部会被压、中间调会偏、肤色会脏。

## 四、这批风格 LUT 各自干什么

| LUT | 风格 | 高光 | 暗部 | 适合 |
|---|---|---|---|---|
| Achromic | 中性、无色偏 | 保留 | 保留 | 想要自然、继续调色 |
| FilmBias | 轻微电影偏色 | 略柔 | 略压 | 电影感、氛围 |
| FilmBiasOffset | 偏色 + 通道偏移 | 柔 | 偏色 | 风格化、特定色调 |
| BleachBypass | 漂白旁路，高对比低饱和 | 保持/略强 | 压缩、加深 | 硬朗电影感、战争/纪实 |

"漂白旁路"（Bleach Bypass）是胶片冲洗工艺：保留银盐、减少染料，结果是**对比高、饱和度低、暗部硬**。它不是"万能电影感"，用在柔和人像上会显得脏。

## 五、LUT 不能恢复信息

LUT 是查找表：输入一个 RGB 值，输出另一个 RGB 值。

- 它能把 Log 的亮度重新分配，但**不能把已经过曝成纯白的高光"变回来"**；
- 它能把暗部提亮，但暗部如果已经低于噪声底，提亮只会放大噪点；
- 不同 LUT 的差别，本质是"压缩曲线陡不陡"：陡 → 高光阴影压得快、对比强；平 → 保留多、画面灰。

所以选 LUT 之前，先问：**我的素材高光有没有保住？暗部有没有欠曝？**素材本身不行，换 LUT 也救不回来。

## 六、正确使用顺序

1. **前期**：N-Log、10bit、基准 ISO、向右曝光半档到一档；
2. **转换**：套尼康官方 `N-Log_to_REC709`，把画面变正常；
3. **基础校正**：曝光、白平衡、对比；
4. **风格**：再叠风格 LUT（Achromic/FilmBias/BleachBypass），用不透明度控制强度；
5. **局部**：曲线、色轮、蒙版精修；
6. **输出**：按交付平台（Rec.709 / HDR）选最终 gamma。

## 七、常见误用

| 误用 | 后果 | 修正 |
|---|---|---|
| 把 RED LUT 当尼康 LUT | 暗部压死、肤色偏 | 用官方 N-Log LUT |
| 直接套风格 LUT 不看曝光 | 曝光判断失真 | 先转换再做基础校正 |
| 风格 LUT 100% 叠加 | 过重、死黑 | 用 30%–70% 不透明度 |
| 8bit 素材套 Log LUT | 断层、色带 | 拍 10bit |
| 以为 LUT 能救过曝 | 高光仍是死白 | 前期控制高光 |

## 要点回顾

- 技术 LUT 管转换，风格 LUT 管影调，顺序不能反。
- 尼康官方 LUT 是 `N-Log_to_REC709`，输入是尼康 N-Log。
- `RED_*` 那批是 Log3G10 → Rec709，套在 N-Log 上会偏色。
- LUT 只映射、不恢复；素材质量决定上限。

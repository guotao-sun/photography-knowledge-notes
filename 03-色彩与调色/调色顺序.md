# 调色顺序

## 先说问题

拿到一张 RAW，很多人上来就拉饱和度、套 LUT，结果越调越脏：肤色偏了、高光断了、暗部糊成一团。

调色不是"按喜好乱拉"，而是一条有依赖关系的流水线：**前面的步骤错了，后面的步骤会放大错误。**这一篇给出可复用的顺序，并纠正两个常见混淆。

## 一、总流程：先修，再定，后风格

| 阶段 | 步骤 | 目的 |
|---|---|---|
| 0. 准备 | 镜头校正、裁剪、水平校正 | 消除畸变、暗角、构图问题 |
| 1. 白平衡 | 色温、色调（Tint） | 先把"中性"调准 |
| 2. 曝光 | 曝光、高光、阴影、黑场、白场 | 把亮度分布拉合理 |
| 3. 对比 | 曲线、对比度 | 建立影调骨架 |
| 4. 色彩 | HSL、饱和度/自然饱和度、色轮 | 定色彩关系 |
| 5. 局部 | 蒙版、渐变、画笔 | 精修主体与环境 |
| 6. 风格 | 分离色调、LUT、颗粒 | 加情绪 |
| 7. 输出 | 降噪、锐化、导出 | 按用途交付 |

## 二、为什么白平衡要在曝光之前

曝光会改变像素值，白平衡是"按比例缩放 RGB 通道"。如果先调曝光再调白平衡，等于在"已经偏色的亮度"上再校色，容易把通道拉断。

正确顺序：**先让画面"中性"（白平衡），再让画面"亮得合理"（曝光），最后才是"好看"（色彩/风格）。**

## 三、曝光阶段的五个滑块

| 滑块 | 作用 | 典型用法 |
|---|---|---|
| 曝光（Exposure） | 整体线性增益，所有像素一起变亮/暗 | 先定整体亮度 |
| 高光（Highlights） | 只压/提亮部 | 救回天空、白纱 |
| 阴影（Shadows） | 只提/压暗部 | 找回暗部细节 |
| 白场（Whites） | 定义"最亮"的边界 | 让画面有"通透的白" |
| 黑场（Blacks） | 定义"最暗"的边界 | 让暗部"沉下去"而不是灰 |

顺序建议：曝光 → 高光/阴影 → 白场/黑场。先定整体，再修两端，最后钉边界。

### 纠正：曝光 vs 亮度

原笔记说"增加曝光改变所有像素，增加亮度优先提暗部"，这只在旧版 Lightroom 的 Brightness 滑块下近似成立。

现代软件（Lightroom Classic、ACR）里：

- **Exposure** 是线性增益，确实所有像素一起变；
- **Brightness**（旧版）偏中间调，不是"优先提暗部"；
- 真正"优先提暗部"的是 **Shadows**。

所以调暗部请用 Shadows，不要用 Brightness 硬提。

## 四、对比与曲线

- **对比度**：整体拉开明暗差，简单但容易压死两端；
- **曲线**：更精细。S 形曲线提对比，左端上提做"雾面"，右端下压做"柔高光"；
- **胶片曲线**：黑场略提（不纯黑）、高光略压（不纯白），中间调微提，得到"灰而不脏"的胶片感。

曲线是调色的"骨架"，HSL 是"血肉"。骨架没立好，颜色再准也不高级。

## 五、色彩阶段

### 1. HSL

| 通道 | 常见操作 |
|---|---|
| 橙色 | 肤色：降饱和、提明度，去黄气 |
| 红色 | 唇色/服装：控制饱和度，避免溢出 |
| 黄色 | 环境/秋叶：降饱和可去"土黄" |
| 绿色 | 植物：色相往黄偏、降饱和，做胶片绿 |
| 蓝色 | 天空/阴影：色相往青偏，提饱和 |
| 紫色/洋红 | 谨慎，容易脏 |

### 2. 饱和度 vs 自然饱和度

- **饱和度**：所有像素一起加浓，饱和的更容易溢出；
- **自然饱和度（Vibrance）**：优先提升低饱和像素，对已经饱和的像素克制。

所以人像先动 Vibrance，别直接拉 Saturation；风光可以两者结合。

## 六、局部精修

- **主体蒙版**：人像提亮脸、压暗背景；
- **渐变蒙版**：天空压暗、地面提亮；
- **径向蒙版**：给主体加"聚光"；
- **画笔**：修局部偏色、脏点。

原则：**局部调整是为了"引导视线"，不是为了"修所有瑕疵"。**每一笔都要能说出"为什么"。

## 七、风格阶段

- **分离色调**：高光暖、阴影冷（青橙），或高光暖、阴影暖（复古）；
- **LUT**：技术 LUT 先转换，风格 LUT 后叠加，强度 30%–70%；
- **颗粒**：加胶片质感，但人像慎用，会放大皮肤噪点；
- **光晕**：Glow/柔焦，压高光、加氛围。

## 八、输出阶段

| 用途 | 锐化 | 降噪 | 色彩空间 |
|---|---|---|---|
| 网络分享 | 中 | 中 | sRGB |
| 打印 | 强（输出锐化） | 低 | Adobe RGB / 印刷 ICC |
| 商业交付 | 按客户要求 | 高 | 按平台 |

顺序：**先降噪，再锐化**。反了会把噪点也锐化出来。

## 九、一张检查清单

- [ ] 镜头校正开了吗？
- [ ] 白平衡中性吗（白纸/灰卡）？
- [ ] 高光有细节吗？暗部有细节吗？
- [ ] 黑场够沉、白场够透吗？
- [ ] 肤色干净吗（橙通道）？
- [ ] 主体比背景亮/清晰吗？
- [ ] 风格强度是否过头？
- [ ] 输出锐化、色彩空间对吗？

## 要点回顾

- 顺序：校正 → 白平衡 → 曝光 → 对比 → 色彩 → 局部 → 风格 → 输出。
- 白平衡在曝光之前，避免"在偏色上校色"。
- 暗部用 Shadows，不是 Brightness。
- 先降噪再锐化，风格强度宁轻勿重。

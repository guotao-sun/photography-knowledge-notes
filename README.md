- `01-构图与取景/` — 构图方法、机位、景别、构图节奏、风景人像

- `03-色彩与调色/` — 白平衡偏移、调色顺序、LUT、人像调色风格
- `04-相机技术与参数/` — EV、光通量、安全快门、档位、景深、ISO、Log、CMOS
- `05-人像姿势与造型/` — 姿势、摆姿、妆造与服化道、道具
- `06-后期处理/` — 锐度、对比度、饱和度、清晰度
- `07-摄影理论与学习/` — 学习路径、职称分级、摄影的本质、筛片方法
- `08-器材与配件/` — 神牛机顶闪、GN 指数
- `images/` — 各篇配图，按章节编号分为 `01/` ~ `08/` 八个子目录，与上面的章节目录一一对应；每个子目录内的 `README.md` 列出该章图片与篇目的对应关系
- `scripts/` — README 目录自动生成脚本

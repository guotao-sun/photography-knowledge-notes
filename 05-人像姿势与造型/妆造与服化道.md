# 妆造与服化道

## 先说问题

"妆造"和"服化道"经常被混着用，沟通时容易漏项：约了化妆师，以为衣服也包了；带了道具，发现和服装色调打架。

两者是**包含关系**，不是并列关系。先把边界分清，拍摄前的准备清单才不会漏。

## 一、定义与边界

| 项目 | 妆造关注 | 服化道关注 |
|---|---|---|
| 化妆 | 是 | 是 |
| 发型 | 是 | 是 |
| 饰品/配件 | 是（小配饰） | 是（整体搭配） |
| 衣服本身 | 否（只看搭配感） | 是（款式、颜色、材质） |
| 道具/场景元素 | 否 | 是 |

- **妆造（Make-up & Styling）**：主要管人物面部和整体气质，可以涉及小配饰和搭配，但不包含完整服装设计；
- **服化道（Costume, Make-up, Props）**：影视/商业摄影里的"美术设计"总称，衣服、化妆、道具、场景全包。

一句话：**妆造是服化道的一部分。**拍个人写真，通常只涉及"妆造 + 服装"；拍商业/影视，才需要完整"服化道"。

## 二、妆造要看的三件事

### 1. 底妆与光

- 闪光/硬光会放大皮肤纹理，底妆要比日常更厚、更哑光；
- 柔光/自然光可以保留皮肤质感，底妆轻薄、带水光；
- 高光位（蝴蝶光）会让额头、鼻梁反光，T 区要重点定妆。

### 2. 发型与轮廓

- 发丝光需要头发有层次，贴头皮的油头拍不出"光边"；
- 圆脸用"头顶蓬松 + 两侧收"的发型，拉长比例；
- 方脸用"侧分 + 波浪"柔化下颌角。

### 3. 色彩与服装

- 肤色偏黄：避开大面积土黄、荧光绿，选米白、雾蓝、灰粉；
- 肤色偏白：可以压深色（墨绿、酒红），避免全白"飘"；
- 环境色强（草地、海边）：服装选对比色或同色系，别"融进去"。

## 三、服化道的协作流程

1. **定主题**：先定风格（清新/复古/电影/商业），再定色彩方案；
2. **定服装**：主色 1–2 个，辅色 1 个，避免超过三种主色；
3. **定妆发**：妆面配合光线（硬光厚、柔光薄），发型配合脸型和轮廓光；
4. **定道具**：道具颜色从服装/环境里"取色"，不要凭空加一个新色；
5. **现场调整**：拍几张看整体，衣服褶皱、妆面反光、道具位置都要现场修。

## 四、常见搭配错误

| 错误 | 问题 | 修正 |
|---|---|---|
| 服装和背景同色同明度 | 人"融"进背景 | 换对比色或加轮廓光 |
| 妆面太厚 + 柔光 | 假面、没质感 | 柔光配薄妆 |
| 妆面太薄 + 硬光 | 瑕疵全出 | 硬光配厚底妆 |
| 道具颜色跳脱 | 画面花 | 道具从环境取色 |
| 配饰太多 | 视觉噪音 | 只留一个"重点配饰" |
| 发型贴头皮 | 拍不出发丝光 | 提前做蓬松/层次 |

## 五、拍摄前清单

- [ ] 主题/风格定了吗？
- [ ] 服装主色、辅色、环境色是否协调？
- [ ] 妆面厚度是否匹配光线（硬光/柔光）？
- [ ] 发型有没有层次，能否拍出发丝光？
- [ ] 道具颜色是否从环境/服装取色？
- [ ] 有没有一个"重点配饰"，其余做减法？
- [ ] 备用服装/补妆工具带了吗？

## 要点回顾

- 妆造 ⊂ 服化道，前者管脸和气质，后者管整体美术。
- 妆面厚度要匹配光质：硬光厚、柔光薄。
- 发型要为轮廓光和脸型服务。
- 服装主色不超过三种，道具从环境取色。

# 相机 ISO 与常见场景

## 先说问题

"ISO 越低画质越好"这句话对，但不够用。实际拍摄中真正的问题是：

- 暗光下到底该提 ISO，还是该降快门、开大光圈？
- 为什么同一台机身在 ISO 800 很干净，ISO 1600 却突然变差？
- 高 ISO 的噪点，是"相机坏了"还是"物理必然"？

## 一、ISO 到底是什么

ISO 不是"感光元件的灵敏度"——CMOS 的物理灵敏度是固定的。ISO 是**增益**：相机把传感器读出的电信号放大多少倍，再映射成亮度值。

- ISO 100 → 基准增益，信号放大 1 倍；
- ISO 1600 → 放大 16 倍，信号和噪声一起放大 16 倍；
- 所以高 ISO 噪点多，本质是"信噪比不足"，不是"相机会制造噪点"。

**关键推论**：在光圈快门已经给足光的情况下，硬把 ISO 拉高再后期压暗，和直接用低 ISO 拍，画质接近（这叫 ISO 不变性，ISO Invariance）。真正伤画质的是"欠曝 + 高 ISO"，不是高 ISO 本身。

## 二、噪点的两种来源

| 类型 | 来源 | 表现 | 应对 |
|---|---|---|---|
| 散粒噪声 | 光子到达的随机性 | 全画面细密颗粒，暗部更明显 | 多进光（大光圈/慢门/补光） |
| 读出噪声 | 电路读出与放大 | 暗部彩噪、条纹 | 现代机身的双增益、后期降噪 |

散粒噪声服从泊松分布，信噪比与光子数的平方根成正比：**进光量翻 4 倍，信噪比才翻 2 倍。**这解释了为什么"提一档 ISO"的代价，远小于"少进一半光"。

## 三、场景对照表（全画幅参考）

| 场景 | 推荐 ISO | 备注 |
|---|---|---|
| 晴天户外、棚拍闪光 | 100–400 | 基准画质区，动态范围最大 |
| 阴天、窗光室内 | 400–1600 | 优先开大光圈 |
| 傍晚、室内活动 | 1600–6400 | 现代全画幅可用区 |
| 夜景手持 | 3200–12800 | 保快门优先，噪点后期处理 |
| 星空 | 1600–6400 | 需配合赤道仪或堆栈 |
| 极暗记录（新闻、取证） | 12800–51200 | "拍到"优先于"拍好" |

APS-C 建议整体降 1–2 档使用（如夜景 1600–6400），M4/3 再降一档。但 2020 年后的背照式传感器进步很大，别用老经验一刀切。

## 四、双增益：为什么有的 ISO 是"台阶"

现代 CMOS 常用双转换增益（Dual Conversion Gain, DCG）：像素内有两个电容，低 ISO 用大电容（容阱大、动态范围高），高 ISO 切到小电容（读出噪声低）。

切换点通常在 ISO 400 或 800（因机型而异）。**跨过切换点后，噪点不一定继续线性变差，甚至可能突然变好一档。**所以：

- 拍暗光时，与其在 ISO 320 硬撑，不如直接上到 ISO 800 或 1600；
- 具体切换点查机型的"输入参考噪点（RN）曲线"，不要凭感觉。

## 五、正确的高感使用顺序

暗光下按这个顺序决策，而不是一上来就飙 ISO：

1. **开大光圈**（先看镜头最大光圈够不够）；
2. **放慢快门**到安全快门下限（开防抖可再降 2–3 档）；
3. **补光**（闪光灯、LED 灯、反光板）；
4. **提 ISO** 到可接受画质的上限；
5. **拍 RAW + 后期降噪**（DxO PureRAW、Lightroom Denoise、Topaz）；
6. **多帧堆栈**（静态场景拍 5–10 张对齐平均，噪点降 √N）。

## 六、三个常见误区

**误区一：ISO 200 一定比 ISO 100 差。**
多数机型 ISO 100 是"扩展低感"，动态范围反而略低；基准 ISO 常是 200（如部分索尼、富士）。查机型手册的"基准 ISO"再判断。

**误区二：高 ISO 会让颜色失真。**
真正让颜色崩的是"欠曝后强拉"。同一曝光水平下，高 ISO 的色彩偏差主要来自降噪算法，不是 ISO 本身。

**误区三：后期降噪可以无限救。**
降噪是"用细节换干净"。ISO 25600 的片子降完噪，皮肤会变成塑料。前期多进一档光，胜过后期十个降噪插件。

## 要点回顾

- ISO 是增益，不是灵敏度；噪点来自信噪比不足。
- 暗光顺序：光圈 → 快门 → 补光 → ISO → 后期。
- 双增益机型有"最佳高感台阶"，ISO 400/800 附近可能反而更干净。
- 拍到比拍好重要，但"欠曝"比"高 ISO"更伤画质。

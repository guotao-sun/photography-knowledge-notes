# 摄影道具

## 先说问题

原笔记只是一串道具名：围巾、帽子、书、杯子、伞、泡泡……没有分类，也没有"什么时候用哪个"。

道具不是"越多越好"，它的作用是解决三个具体问题：**手没地方放、画面太空、故事感不足。**按用途分类，才知道该带什么。

## 一、按用途分四类

### 1. 解决"手"的道具

| 道具 | 用法 | 适合 |
|---|---|---|
| 杯子/热饮 | 双手捧、单手拿、靠近嘴边 | 咖啡馆、居家、冬日 |
| 书/杂志 | 翻、抱、遮半脸 | 文艺、室内、书店 |
| 帽子 | 扶帽檐、拿在手里、遮阳 | 户外、旅行、复古 |
| 围巾 | 绕、拉、挡风 | 秋冬、海边、街拍 |
| 包 | 单肩、手提、抱在胸前 | 街拍、通勤、都市 |
| 相机/手机 | 举拍、低头看 | 旅行、纪实、生活感 |

### 2. 解决"空"的道具

| 道具 | 作用 |
|---|---|
| 花/花束 | 填补前景、增加色彩 |
| 气球 | 大面积色块、童趣 |
| 泡泡 | 动态元素、梦幻 |
| 伞 | 框架、遮阳、雨天氛围 |
| 叶子/树枝 | 前景遮挡、自然感 |
| 毯子/野餐篮 | 铺地、坐姿支点 |

### 3. 制造"动"的道具

- 泡泡机：边吹边拍，抓动态；
- 风车/风筝：有风时产生运动；
- 飘带/裙摆：走动、转身时飘起来；
- 水/沙子：海边、溪边，抓水花。

### 4. 制造"故事"的道具

- 旧书、老相机、胶片机：复古叙事；
- 信件、地图、车票：旅行故事；
- 乐器：表演感、文艺感；
- 食物：生活感、烟火气。

## 二、选道具的三条原则

1. **从场景取色**：道具颜色要么呼应服装，要么呼应环境，不要凭空加一个新色；
2. **一个重点就够**：一次只用一个"主角道具"，其余做背景；
3. **能互动**：道具要能"用起来"（喝、看、扶、吹），不能只是"拿着"。

## 三、按场景的道具清单

| 场景 | 推荐道具 |
|---|---|
| 咖啡馆/室内 | 杯子、书、耳机、笔记本 |
| 街头/城市 | 包、墨镜、咖啡、报纸、单车 |
| 海边 | 草帽、裙子、纱巾、贝壳、泡泡 |
| 草地/原野 | 野餐篮、毯子、花、风筝 |
| 秋冬户外 | 围巾、毛衣袖子、热饮、落叶 |
| 居家 | 抱枕、毯子、马克杯、宠物 |
| 复古/胶片 | 老相机、胶片、旧书、唱片 |

## 四、常见错误

- **道具太多**：画面像"杂货铺"，主体被淹没；
- **道具太新**：塑料感强，和复古/自然风格冲突；
- **道具和服装撞色**：红裙 + 红气球，人融进道具；
- **只拿不用**：举着杯子不喝、抱着书不翻，姿势还是僵；
- **道具抢戏**：道具比脸亮/比脸大，视线被带走。

## 五、收纳与现场

- 道具装一个箱子，按"手/空/动/故事"分袋；
- 易碎、易脏的道具（杯子、花）备双份；
- 现场先拍"有道具"的，再拍"没道具"的，方便选片；
- 拍完检查道具是否入镜边缘、有没有穿帮（标签、logo）。

## 要点回顾

- 道具解决三件事：手、空、故事。
- 按"手/空/动/故事"四类带，不要乱带。
- 颜色从场景取，一个重点就够。
- 道具要能互动，不能只是拿着。
